# Neil Smith Construction Ltd. website

Single-page website for Neil Smith Construction Ltd., a heavy civil contractor in Metro Vancouver and the Fraser Valley.

## Files
- `index.html` is the whole site (styles, scripts, logo and project drawings are built in)
- `nsc-logo.jpg` is used for the browser tab icon and link previews

## Publish with GitHub Pages
1. Upload both files to the root of the repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then **Save**.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

To use your own domain (for example neilsmithconstructionltd.com), enter it under **Settings → Pages → Custom domain** and point your DNS to GitHub Pages.
